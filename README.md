# 💰 Expense Tracker App

A simple, responsive, and interactive **Expense Tracker Web App** built using **HTML, CSS, and JavaScript**.  
It allows you to **set a budget**, **add expenses**, **track balance in real-time**, and automatically **save data using localStorage**, so your data persists even after reloading the page.

---

## 🚀 Features

- 🏦 **Add & Update Budget** — Set your total budget easily.  
- 💸 **Add Expenses** — Record expense title and amount.  
- 📊 **Automatic Calculations** — Instantly see total expenses and remaining balance.  
- 🧮 **LocalStorage Integration** — Your data (budget and expenses) stays even after refresh.  
- ❌ **Delete Individual Expenses** — Remove any expense and the total updates automatically.  
- 🔄 **Reset Button** — Quickly clear all data and start fresh.  
- 🎨 **Modern UI Design** — Smooth shadows, responsive layout, and pastel theme.

## 🖥️ How It Works

1. **Enter a Budget**  
   Add your total budget and click on **"Add Budget"**.

2. **Add Expenses**  
   - Enter expense name and amount.  
   - Click **"Add Expense"** to log it.  
   - The expense appears in the list with a delete button ❌.

3. **Track Balance**  
   - The app automatically calculates total expenses and remaining balance.

4. **Delete or Reset**  
   - Click ❌ to delete a specific expense.  
   - Use **"Reset"** to clear everything.
